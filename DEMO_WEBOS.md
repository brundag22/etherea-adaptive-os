# Etherea WebOS Demo Script (3–5 min)

1. **Launch shell (30s)**
   - Open dashboard and point out offline-first startup and privacy default.
2. **Workspaces flow (60s)**
   - Go to Workspaces, open one detail view, show status and notes context.
3. **Natural language command bar (60s)**
   - Run a command in Ethera bar (e.g., "summarize diagnostics").
   - Show output and matching diagnostics log entry.
4. **Diagnostics view (45s)**
   - Open diagnostics and explain client-side logs only.
5. **Settings + kill switch (45s)**
   - Toggle theme, privacy, analytics opt-in, and command bar kill switch.
   - Reopen command bar to show kill switch behavior.
6. **Close with deployment readiness (30s)**
   - Mention CI and Firebase hosting workflow gates.
